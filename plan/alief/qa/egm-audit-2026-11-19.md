# EGM audit — bugs + deprecated code (19 Nov 2026)

Method: Google [Elephant-Goldfish Model](https://github.com/google/elephant-goldfish-model). Elephant = the session with full project context (mapped the repo, ran the build and typecheck, verified findings). Goldfish = two fresh subagents with no history, reading only the PRD pointer, `contracts/api.md`, the folder `CLAUDE.md`, and the code:
1. **UI / user POV**: walked every flow as a Protected parent (older, low vision, Bahasa Indonesia) and as a Guardian.
2. **Backend**: auth, races, retention, contract drift, deprecated APIs.

Each goldfish finding was re-checked against the code at `origin/main` 129e1336. Verdict: **CONFIRMED** (read the code and it does this), **PLAUSIBLE** (code supports it, needs a simulator or load test), or left out.

Tooling results:
- `xcodebuild` clean build (scheme `Shoo`, iOS 26.3 sim): 0 errors, 1 real warning: `ShooApp/Components/SiteIcon.swift:106` `now: @escaping @Sendable () -> Date = Date.init` (non-Sendable function value, Swift 6). Fix: `= { Date() }`. No deprecation warnings at deployment target iOS 17.
- `tsc --noEmit` and `--noUnusedLocals --noUnusedParameters`: clean.
- `pnpm outdated`: all 7 packages behind. Major bumps: `postgres` 3→4, `typescript` 5→7, `vitest` 4→5. Minor bumps: `hono` 4.13.19, `wrangler` 4.164, `@cloudflare/*`.

Owner column: **Alief** = `ios/ShooApp/` or `backend/`. **Lead** = `contracts/` or `ios/ShooExtension/`, which needs a GitHub issue (CLAUDE.md rule 7).

## 🟢 Nits (goldfish, spot-checked)
- `ShooApp/Features/Onboarding/NameView.swift:131` — a name over 20 characters greys out Next with no red error or counter.
- `ShooApp/Features/Profile/ProfileSheets.swift:334`, `ProfileStyle.swift:711` — the Delete card and confirm sheet are `fixedSize` with no ScrollView. At AX5 text size the buttons can go off screen.
- `ShooApp/App/AppSettings.swift:270` — "Set up again" after session expiry also resets text size, bold and contrast.
- `ShooApp/App/Router.swift:60` — an invite code from a link opened before onboarding is kept in memory only, so it is lost if iOS kills the app in Settings.
- `ShooApp/Data/ExtensionStatus.swift:90` — the Safari state callback has no timeout, and Home waits on it.
- `ShooApp/Features/Pairing/ConnectModel.swift:81` — code `000000` enters a demo family silently. "Delete account" then claims real deletion.
- `ShooApp/Features/Pairing/InviteSheet.swift:166` — 503 and 429 both say "Check your internet connection".
- `backend/api/src/routes/terms.ts:21` — "Either side can disconnect", but the Protected disconnect is locked. `support.ts:72` — "tap Safe" also shows to Protected users, who have no Safe button.
- `backend/api/src/services/favicons.ts:96` — any device can pin the archive favicon of any domain (first write wins).
- `backend/api/src/services/push/notify.ts:24` — `PUSH_CAP` is counted after send, so parallel scans can pass it.
- `backend/api/src/db/repo/scans.ts:78` — the cursor pages on `detected_at`, which moves on repeat visits, so rows repeat or get skipped. A client `detectedAt` back to 1970 is accepted.
- `backend/api/src/cron/notifications.ts:154` — the weekly-summary query has no LIMIT and runs every hour.
- `backend/api/src/routes/scans.ts:73` — stores the full URL with query string and relies on the client to strip it.
