Alur inti jalan dari ujung ke ujung di simulator: onboarding Guardian + Protected (EN dan ID) mendaftar ke backend sungguhan, pairing lewat kode yang diketik dan lewat link `shoo://join?code=` (kode terisi, tidak join sendiri), Guardian melihat Mom + Dad di Family Shield, push yang di-tap membuka Detail di ketiga keadaan app (foreground, background, dimatikan) dalam ±4–6 s termasuk tap, dan "It's safe" langsung terbaca oleh Protected lewat `GET /verdicts` (150–600 ms setelah tap).

Skenario API keamanan lulus semua (46 cek di `qa/api-e2e.sh`): token salah/kosong 401, IDOR scan keluarga lain 404, verdict dari Guardian lain `verdict_not_allowed`, `ownerDeviceId`/`ownerName` palsu di body diabaikan, brute force kode `too_many_attempts` 429 + `Retry-After` setelah 6 percobaan, keluarga penuh `family_full`, kode kedaluwarsa `code_expired`, retensi 14 hari menghapus scan lama, `DELETE /devices/me` mematikan token.

Tidak ada bug app. Yang gagal di awal adalah 4 UI test live yang basi terhadap UI sekarang (langkah "Hi, nama!" sudah hilang, tombol Profile hanya di Shield, `FamilyCodeView` diganti `InviteSheet`, Detail menyembunyikan tab bar, prompt "Open in Shoo?" hanya sekali per simulator, consent lewat launch argument hilang saat app di-cold-start oleh push). Test diperbarui di PR ini, bukan app-nya. Satu temuan P2 butuh keputusan desain (P2-1).

# Detail temuan

## P2-1 · Guardian dengan anggota tetap "Personal" sampai Family mode dinyalakan

P2 · GD-02 / PF-01

Langkah: 1) Install baru, onboarding pilih Guardian (Rina). 2) Profile → Share invite, dua Protected (Mom, Dad) join. 3) Tutup sheet undangan, lihat Profile.

Hasil: Profile menulis "@rina · Personal", baris Account mode "Personal", dan kartu "GUARDIAN MODE · Become a Guardian" tampil. Bagian Connected tidak menampilkan Mom/Dad. Shield tetap tampilan pribadi sampai tombol Family mode ditekan; setelah itu Family Shield menampilkan Mom + Dad (Active).

Harapan: perlu keputusan. Kemungkinan: (a) Family mode menyala otomatis saat anggota pertama join, atau (b) kartu "Become a Guardian" disembunyikan untuk Guardian yang sudah punya anggota. Kode: `ProfileModel.variant` (`familyModeOn ? .guardian : .personal`) dan `showsGuardianCard` (`variant == .personal`); `familyModeOn` hanya berubah lewat toggle (D-alief-A15) atau `becomeGuardian()`.

Catatan: bukan regresi (desain D Q5: anggota tetap tersambung saat Family mode mati). Push ke Guardian tetap terkirim apa pun status toggle. Tidak diperbaiki sepihak: butuh jawaban desainer/Umar.

Bukti: QA-E2E/03_guardian_family_2.png — Family Shield setelah toggle dinyalakan (Mom + Dad Active). Pohon aksesibilitas sebelum toggle tercatat di log run (`profile.guardianCard`, "Personal").
