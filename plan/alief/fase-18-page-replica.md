## Tujuan

Bukti di Detail menjadi **salinan halaman** (DOM statis dari extension) menggantikan screenshot yang sering tidak sempat diambil. Alurnya tersambung ujung ke ujung: extension (PR #178 Umar) → `POST /scans` (`pageReplicaBase64`) → bucket privat → `GET /scans/{id}` (`pageReplicaUrl`, link Worker 1 jam) → Detail merender salinan tanpa JavaScript dan tanpa jaringan. Scan lama tetap menampilkan `screenshotUrl` sampai habis retensi 14 hari.

**Keadaan 29 Okt:** PR #178 sudah merge ke `main` 29 Okt 04:05 UTC (a57c531), **sebelum** 18a. Extension di `main` tidak lagi mengirim screenshot (`capture.js` dihapus di 965d871, `report.js:99-113` hanya mengirim replica). Backend `main` membuang `pageReplicaBase64` (`z.object` strip, `routes/scans.ts:46`) atau membalas 413 di atas 256 KB (`app.ts:35,47`) lalu extension kirim ulang tanpa replica (`background.js:153`). Scan tidak hilang, tetapi **scan baru dari build `main` tidak punya bukti** sampai 18a ter-deploy (replica sebelum itu tidak bisa dipulihkan) dan Detail kosong sampai 18b merge (`DetailView.swift:70` menyembunyikan blok bukti). Build TestFlight yang sudah terpasang tidak terdampak. Mitigasi = gerbang D-alief-C24 (K16).
